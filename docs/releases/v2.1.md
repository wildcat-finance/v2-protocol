## Changes from V2.0

V2.1 is one source commit beyond V2.0. Its production source delta adds only:

- `Wildcat4626Wrapper`, a non-rebasing ERC-4626 share token backed by scaled
  Wildcat market-token ownership.
- `Wildcat4626WrapperFactory`, which permissionlessly deploys at most one
  wrapper for a registered market.

Core market, hook, accounting, ArchController, sanctions, and lens source stays
unchanged. The release also adds wrapper tests, deployment tooling, and
integration documentation.

## Deployment and compatibility

The V2.1 tag does not include a wrapper-factory address in its retained mainnet
deployment file. Current deployment facts, including the later wrapper-factory
deployment, live in [`deployments/`](../../deployments/).

V2.1 wrappers target pre-V2.5 markets and inherit their half-up transfer
rounding. Current wrapper behavior and cross-generation routing are documented
in [ERC-4626 wrapper](../integrations/erc-4626-wrapper.md).
